Cookie information

Last updated: 2026-09-30

This website

The GregyScan website is a static website.

GregyScan does not intentionally add:

  • analytics cookies
  • advertising cookies
  • tracking pixels
  • behavioral tracking
  • embedded advertising
  • third-party marketing widgets
  • account cookies

The site also does not use a GregyScan account or login system.

Cookie consent

Because the GregyScan website does not intentionally set optional advertising or analytics cookies, GregyScan does not display its own cookie-consent banner.

If the website changes in the future and optional tracking technologies are introduced, this information and any required consent mechanism will be updated before those technologies are enabled.

GitHub Pages hosting

The GregyScan website may be hosted through GitHub Pages.

GitHub receives ordinary network requests required to serve the website and may process information such as IP addresses, browser information and service logs for security, reliability and operation of its services.

This processing is controlled by GitHub and is subject to the GitHub General Privacy Statement .

Browser caching

Browsers may locally cache public website files such as HTML pages, stylesheets and images to improve loading performance.

Browser caching is technically different from advertising or behavioral tracking.

External links

The GregyScan website contains links to external services such as:

  • GitHub
  • Buy Me a Coffee
  • email services
  • Google documentation

These services are not controlled by GregyScan.

When you follow an external link, the destination service may use its own cookies, analytics or other technologies according to its own privacy and cookie policies.

GregyScan Android application

This cookie information applies to the GregyScan website.

The current public GregyScan Android release does not contain advertising SDKs, first-party analytics or a GregyScan account system.

More information about application data handling is available in the Privacy Policy.

Changes

This page may be updated if the website, hosting setup or data-handling behavior changes.
