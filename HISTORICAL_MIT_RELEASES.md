# Historical MIT Releases

This file is retained for historical and licensing reference.

GregyScan continues development based on earlier open-source work from ScanIt / SeliaScan.

The historical release information below belongs to the original ScanIt / SeliaScan project and is preserved only to document its earlier MIT-licensed releases and licensing history.

GregyScan starts its own release history with version **1.0.0**.

---

ScanIt changed to source-visible proprietary terms for new material at the
license-cutoff commit planned for release as `v1.2.0-beta.2`.

The change is prospective. It does not revoke rights granted for any copy that
was already distributed under the MIT License. Those copies may continue to be
used, copied, modified, merged, published, distributed, sublicensed, or sold
under their original MIT terms.

Known pre-cutoff distributions include:

- [`v1.0.0-preview.1`](https://github.com/Majkey25/ScanIt/releases/tag/v1.0.0-preview.1), version code 1.
- [`v1.1.0-alpha.1`](https://github.com/Majkey25/ScanIt/releases/tag/v1.1.0-alpha.1), version code 2.
- The previously distributed `v1.1.0-alpha.2` Google Play test artifact, version code 4.
- Repository source and other artifacts distributed before the proprietary cutoff while the root `LICENSE` contained the MIT License.

The immutable tags and release assets above retain the license that accompanied
them. Later commits and releases are not MIT-licensed merely because they are
derived from a historical MIT version; check the `LICENSE` included with the
specific copy.
